# إرشادات التصميم والاتجاه من اليمين إلى اليسار (RTL Guidelines)

يهدف هذا الدليل إلى ضمان تجربة استخدام متسقة ومثالية للغة العربية في نظام إدارة السائقين مع الالتزام الصارم بالقواعد المعمارية.

---

## 1. الخصائص المنطقية في Tailwind CSS (Logical Properties Only)

يُمنع منعاً باتاً استخدام كلاسات الاتجاهات الفيزيائية القديمة (`ml-*`, `mr-*`, `pl-*`, `pr-*`, `left-*`, `right-*`). 
يجب استخدام **الخصائص المنطقية** فقط في كافة المكونات:

| الخاصية الفيزيائية الممنوعة | الخاصية المنطقية البديلة | الوظيفة في نمط RTL العربي |
|---|---|---|
| `ml-*` (margin-left) | `ms-*` (margin-inline-start) | هامش البداية (من جهة اليمين في RTL) |
| `mr-*` (margin-right) | `me-*` (margin-inline-end) | هامش النهاية (من جهة اليسار في RTL) |
| `pl-*` (padding-left) | `ps-*` (padding-inline-start) | حشو البداية (من جهة اليمين في RTL) |
| `pr-*` (padding-right) | `pe-*` (padding-inline-end) | حشو النهاية (من جهة اليسار في RTL) |
| `text-left` / `text-right` | `text-start` / `text-end` | محاذاة النص لبداية أو نهاية السطر منطقياً |
| `rounded-l-*` / `rounded-r-*` | `rounded-s-*` / `rounded-e-*` | تدوير حواف بداية/نهاية العنصر |
| `border-l-*` / `border-r-*` | `border-s-*` / `border-e-*` | حدود بداية/نهاية العنصر |

## 2. قواعد عكس الأيقونات (Icon Mirroring Rules)

لا ينبغي عكس جميع الأيقونات عند الانتقال إلى RTL:

### أيقونات يجب عكسها (`rtl:rotate-180`):
- أيقونات الأسهم التي تشير إلى التدفق الزمني للأمام والخلف (مثل: أسهم الرجوع، الأسهم المتجهة لليسار واليمين في التنقل والتمرير).
- أيقونات خطوات المعالج المتتابعة (Next / Previous).

```tsx
<ArrowLeft className="w-4 h-4 rtl:rotate-180" />
```

### أيقونات لا يجوز عكسها:
- الأيقونات التي تعبر عن أشياء واقعية متناظرة (مثل: البحث 🔍، الإعدادات ⚙️، المستخدم 👤، التقويم 📅، سلة المهملات 🗑️).
- أيقونات الاتجاهات الثابتة (مثل اتجاه البوصلة أو الساعة 🕒).
- شارات وأيقونات وسائل التواصل (مثل WhatsApp).

## 3. الخطوط والأرقام (Typography & Numbers)

1. **الخط المعتمد:** خط **Cairo** المضمن ذاتياً عبر حزمة `@fontsource/cairo` للأوزان (400, 500, 600, 700).
2. **أرقام الهواتف:** تُعرض دائماً بنظام الترقيم اللاتيني مع علامة `+` في البداية وتُغلف بخاصية `dir="ltr"` لمنع تشويه الترتيب:
   ```tsx
   <span dir="ltr" className="font-mono text-sm">+201012345678</span>
   ```
3. **الأرقام المالية والكمية:** تُنسق وتُعرض بنسق واضح ومقروء.
