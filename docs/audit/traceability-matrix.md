## 12. EXTRA Features (Discovered in Code but Not in Phase Plans)

1. **Streaming Fast CSV Drivers Exporter (`StreamingDriversExport.php`):**
   - Automatically swaps the queued PhpSpreadsheet exporter for a memory-efficient streamed CSV exporter when driver count exceeds 1,000. Not requested in Phase 7 plan, but added to survive 128MB shared hosting memory constraints.
2. **Encrypted Database Backups (`BackupDatabaseCommand.php` with `--encrypt`):**
   - AES-256-CBC encryption of database dumps using the application's `APP_KEY`. Optional feature exceeding base Phase 8 backup requirements.
3. **Database Restore Command (`app:restore-db`):**
   - Fully automated command to decrypt and restore database backups with interactive confirmation, safety guards against production execution without force flag, and automatic migration status verification.
4. **Reconcile Work Order Notifications Command (`work-orders:reconcile-notifications`):**
   - Self-healing scheduled command running every 5 minutes to detect confirmed or backup recipients who did not receive an outbound message (e.g. if worker crashed mid-batch) and idempotently re-dispatches notification messages.
5. **Lucide Icons Library (`lucide-react`):**
   - Added to frontend for icons throughout the dashboard, drawer, and tables alongside HeroUI. Documented in ADR 003.
