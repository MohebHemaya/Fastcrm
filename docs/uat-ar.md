# دليل اختبار القبول للمستخدم (UAT) — نظام إدارة السائقين

هذا الدليل مخصص لإجراء اختبارات القبول الميدانية (User Acceptance Testing) للتحقق من جاهزية النظام للتشغيل الفعلي. يحتوي كل سيناريو على خطوات التنفيذ والنتيجة المتوقعة وحالة الاختبار (ناجح / راسب) مع حقل للملاحظات.

---

## 1. المصادقة وإدارة الجلسة (Authentication & Access Control)

| المعرف | السيناريو | خطوات الاختبار | النتيجة المتوقعة | الحالة (ناجح/راسب) | الملاحظات |
| :---: | :--- | :--- | :--- | :---: | :--- |
| **AUTH-01** | تسجيل الدخول ببيانات صحيحة | 1. الانتقال إلى شاشة الدخول.<br>2. إدخال البريد الإلكتروني وكلمة المرور الصحيحة.<br>3. الضغط على "تسجيل الدخول". | يتم تسجيل الدخول بنجاح والتوجيه إلى لوحة المؤشرات الرئيسية، وظهور اسم المستخدم. | [ ] | |
| **AUTH-02** | تسجيل الدخول ببيانات غير صحيحة | 1. إدخال بريد إلكتروني أو كلمة مرور خاطئة.<br>2. الضغط على "تسجيل الدخول". | تظهر رسالة خطأ واضحة باللغة العربية: "بيانات الاعتماد المدخلة غير صحيحة"، ولا يتم فتح الجلسة. | [ ] | |
| **AUTH-03** | الحماية من التخمين المتكرر (Rate Limiting) | 1. محاولة إدخال كلمة مرور خاطئة 5 مرات متتالية. | يتم حظر المحاولات وتظهر رسالة تفيد بتجاوز عدد المحاولات المسموح بها مع وقت الانتظار. | [ ] | |
| **AUTH-04** | تسجيل الخروج | 1. الضغط على زر "تسجيل الخروج" من القائمة العلوية. | إنهاء الجلسة فوراً، وإلغاء صلاحية الرمز المميز، والتحويل لشاشة الدخول. | [ ] | |

## 2. استيراد السائقين ومعالجة الملفات (Driver Import & Verification)

| المعرف | السيناريو | خطوات الاختبار | النتيجة المتوقعة | الحالة (ناجح/راسب) | الملاحظات |
| :---: | :--- | :--- | :--- | :---: | :--- |
| **IMP-01** | رفع ملف إكسيل سليم ومعاينته | 1. التوجه لصفحة "استيراد السائقين".<br>2. اختيار ملف إكسيل يحتوي على 50 سائقاً بصيغة صحيحة.<br>3. فحص المعاينة وتطابق الأعمدة. | تظهر شاشة المعاينة تعرض عدد الصفوف الصالحة بدقة، مع تمييز الحقول دون أخطاء. | [ ] | |
| **IMP-02** | تأكيد الاستيراد وحفظ البيانات | 1. الضغط على "تأكيد واستيراد". | تظهر شاشة تقدم، وتتم إضافة السائقين بنجاح لقاعدة البيانات مع إشعار نجاح باللغة العربية. | [ ] | |
| **IMP-03** | استيراد ملف يحتوي على أرقام هواتف مكررة أو خاطئة | 1. رفع ملف يحتوي على أرقام غير مطابقة للصيغة أو مكررة. | يكتشف النظام الأخطاء ويعرض تقريراً بصفوف الأخطاء وسبب رفض كل صف بوضوح. | [ ] | |

| **DRV-01** | البحث عن سائق بالاسم ورقم الهاتف | 1. كتابة جزء من اسم السائق أو رقمه في شريط البحث. | تصفية الجدول فوراً لإظهار النتائج المطابقة فقط بسرعة عالية. | [ ] | |
| **DRV-02** | الفلترة حسب الحالة والمحافظة | 1. تصفية السائقين حسب المحافظة وحالة التوفر. | تحديث الجدول لعرض السائقين المطابقين لمعايير الفلترة المحددة. | [ ] | |
| **DRV-03** | تعديل بيانات سائق | 1. فتح ملف سائق وتعديل رقم الهاتف أو المحافظة.<br>2. الضغط على حفظ. | حفظ التعديلات بنجاح وظهور إشعار تأكيد وتحديث البيانات في الجدول. | [ ] | |

## 4. التواصل عبر واتساب والاستبيان (WhatsApp & Questionnaires)

| المعرف | السيناريو | خطوات الاختبار | النتيجة المتوقعة | الحالة (ناجح/راسب) | الملاحظات |
| :---: | :--- | :--- | :--- | :---: | :--- |
| **WA-01** | إرسال دعوة جماعية للانضمام | 1. تحديد 5 سائقين جدد.<br>2. الضغط على "إرسال دعوات الانضمام". | إدراج الرسائل في قائمة الانتظار، وتحديث حالة السائق إلى "تم إرسال الدعوة". | [ ] | |
| **WA-02** | استقبال رد السائق وتحديث الحالة تلقائياً | 1. رد السائق بكلمة "نعم" أو الموافقة عبر واتساب. | معالجة الـ Webhook تلقائياً، وتحديث حالة السائق فوراً في لوحة التحكم دون تحديث الصفحة. | [ ] | |
| **WA-03** | تعبئة الاستبيان التفاعلي | 1. إرسال أسئلة الاستبيان للسائق (نوع المركبة، المحافظة).<br>2. استلام الإجابات. | تسجيل الإجابات وتحديث بطاقة السائق بكافة الخصائص المستلمة. | [ ] | |
| **WA-04** | طلب عدم الإزعاج (Opt-out) | 1. رد السائق بكلمة "إيقاف" أو "STOP". | حظر إرسال أي رسائل ترويجية أخرى وتحديث حالة السائق إلى "غير متاح للتواصل". | [ ] | |

## 5. إدارة أوامر التشغيل وتوزيع الحصص (Work Orders & Quotas)

| المعرف | السيناريو | خطوات الاختبار | النتيجة المتوقعة | الحالة (ناجح/راسب) | الملاحظات |
| :---: | :--- | :--- | :--- | :---: | :--- |
| **ORD-01** | إنشاء أمر تشغيل جديد بالحصص الأساسية والاحتياطية | 1. الدخول على "أوامر التشغيل".<br>2. إنشاء أمر تشغيل (المطلوب: 10 أساسي + 5 احتياطي).<br>3. تحديد الموقع وتاريخ البدء والأجر. | إنشاء أمر التشغيل بنجاح مع إظهار بطاقات العد التنازلي والمقاعد المتبقية. | [ ] | |
| **ORD-02** | إرسال عروض العمل للمرشحين | 1. إرسال عروض التشغيل لـ 30 سائقاً مطابقاً. | إرسال رسائل القالب عبر واتساب مع أزرار القبول والاعتذار. | [ ] | |
| **ORD-03** | قبول السائقين واكتمال الحصة الأساسية ثم الاحتياطية | 1. قبول أول 10 سائقين للعرض.<br>2. قبول 5 سائقين آخرين. | وضع أول 10 في قائمة "المؤكدين"، والـ 5 التاليين في "قائمة الاحتياط" تلقائياً مع إشعار السائق بوضعه. | [ ] | |
| **ORD-04** | اعتذار سائق مؤكد وتصعيد الاحتياطي تلقائياً | 1. تسجيل اعتذار سائق مؤكد (أو إلغاؤه يدوياً). | تصعيد أول سائق من قائمة الاحتياط تلقائياً إلى القائمة الأساسية وإرسال رسالة تأكيد له. | [ ] | |
| **ORD-05** | إتمام أمر التشغيل وتسجيل الحضور الفعلي | 1. الضغط على "إتمام أمر التشغيل".<br>2. تحديد حالة الحضور والغياب لكل سائق. | حفظ سجلات الحضور وتحديث مؤشرات الأداء وإغلاق أمر التشغيل. | [ ] | |
